# Руководство для менеджера проекта - Модульная торговая система

## 🎯 Обзор системы

Торговая система состоит из **четырех независимых модулей**, которые работают как отдельные программы и взаимодействуют через файлы. Это как конвейер: каждый модуль выполняет свою задачу и передает результат следующему.

### Архитектура системы (простыми словами):
```
📊 Сбор данных → 🧮 Тестирование стратегий → 📋 Создание отчетов → 🤖 Торговля (будущее)
```

---

## 📦 Описание модулей

### Модуль 1: Сборщик исторических данных
**Что делает**: Скачивает исторические данные о ценах с биржи Bybit  
**Входные данные**: Символ криптовалюты (например, SOLUSDT), временной период  
**Результат**: CSV или JSON файлы с историческими ценами  

**Пример использования**:
```bash
python -m modules.data_collector --symbol SOLUSDT --timeframe 5m --period week
```

**Что получим**: Файл `SOLUSDT_5m_20241212_20241219.csv` с ценами за неделю по 5-минутным интервалам

---

### Модуль 2: Система бэктестинга
**Что делает**: Тестирует торговые стратегии на исторических данных  
**Входные данные**: Файл со стратегией + файл с историческими данными  
**Результат**: JSON файл с результатами тестирования (прибыль, убытки, статистика)  

**Пример использования**:
```bash
python -m modules.backtester --strategy ./strategy.py --data ./data/SOLUSDT_5m.csv
```

**Что получим**: Файл `backtest_results_20241219_143522.json` с подробной статистикой торговли

---

### Модуль 3: Генератор отчетов
**Что делает**: Создает красивые HTML отчеты с графиками из результатов бэктестинга  
**Входные данные**: JSON файл с результатами тестирования  
**Результат**: HTML файл с интерактивными графиками и анализом  

**Пример использования**:
```bash
python -m modules.reporter --results ./backtest_results.json --template comprehensive
```

**Что получим**: HTML отчет, который можно открыть в браузере с графиками прибыли, рисков и статистикой

---

### Модуль 4: Торговый бот (пока заготовка)
**Что делает**: В будущем будет выполнять реальную торговлю  
**Текущий статус**: Только структура, реальной торговли нет  
**Планы**: Интеграция с биржей, исполнение сделок, мониторинг  

---

## 🔄 Полный рабочий процесс

### Шаг 1: Сбор данных (5-10 минут)
```bash
# Скачиваем недельные данные по SOLUSDT с 5-минутными свечами
python -m modules.data_collector --symbol SOLUSDT --timeframe 5m --period week --format csv
```
**Результат**: Файл `data/raw/SOLUSDT_5m_20241212_20241219.csv`

### Шаг 2: Создание стратегии (разработка)
Создаем файл `examples/strategies/my_strategy.py`:
```python
from modules.backtester import StrategyBase, MarketData, Position, TradeSignal, Signal

class SimpleMA(StrategyBase):
    def _initialize(self):
        self.parameters = {'fast_ma': 10, 'slow_ma': 20}
        self.state = {'prices': []}
    
    def on_bar(self, data, position):
        self.state['prices'].append(data.close)
        
        if len(self.state['prices']) >= 20:
            fast_avg = sum(self.state['prices'][-10:]) / 10
            slow_avg = sum(self.state['prices'][-20:]) / 20
            
            if fast_avg > slow_avg and position.direction == "NONE":
                return TradeSignal(signal=Signal.BUY, reason="Fast MA above Slow MA")
            elif fast_avg < slow_avg and position.direction == "LONG":
                return TradeSignal(signal=Signal.CLOSE_LONG, reason="Fast MA below Slow MA")
        
        return TradeSignal(signal=Signal.HOLD)
```

### Шаг 3: Тестирование стратегии (2-5 минут)
```bash
# Тестируем стратегию на собранных данных
python -m modules.backtester \
    --strategy ./examples/strategies/my_strategy.py \
    --data ./data/raw/SOLUSDT_5m_20241212_20241219.csv \
    --capital 10000 \
    --output ./output/backtests/my_strategy_results.json
```
**Результат**: Файл `output/backtests/my_strategy_results.json` с результатами

### Шаг 4: Создание отчета (1-2 минуты)
```bash
# Генерируем HTML отчет
python -m modules.reporter \
    --results ./output/backtests/my_strategy_results.json \
    --template comprehensive \
    --theme professional
```
**Результат**: HTML файл `output/reports/SimpleMA_Report_20241219_144530.html`

### Шаг 5: Просмотр результатов
Открываем HTML файл в браузере и анализируем:
- График изменения капитала
- Статистику сделок (прибыльность, риски)
- Распределение прибылей и убытков
- Рекомендации по улучшению

## 📊 Что показывают отчеты

### Основные метрики:
- **Общая доходность**: Сколько заработала стратегия (в %)
- **Максимальная просадка**: Самый большой убыток подряд
- **Коэффициент Шарпа**: Отношение прибыли к риску
- **Процент прибыльных сделок**: Как часто стратегия выигрывает
- **Средняя сделка**: Средняя прибыль/убыток за сделку

### Визуализация:
- **График капитала**: Как менялся баланс во времени
- **Распределение сделок**: Гистограмма прибылей и убытков
- **Помесячная доходность**: Прибыль по месяцам
- **Метрики рисков**: Сравнение с эталонными показателями

## 🛠️ Управление модулями

### Независимость модулей
**Ключевая особенность**: Каждый модуль работает отдельно  
- Можно обновлять один модуль, не трогая другие
- Можно тестировать модули по отдельности
- Разные разработчики могут работать над разными модулями

### Стандарты взаимодействия
**Входы/Выходы строго определены**:
- Модуль 1 → CSV/JSON файлы с данными
- Модуль 2 → JSON файлы с результатами
- Модуль 3 → HTML файлы с отчетами
- Модуль 4 → (планируется) сделки на бирже

# Проверить готовые отчеты

### Массовое тестирование стратегий:
```bash
# Протестировать все стратегии на всех данных
for strategy in examples/strategies/*.py; do
    for data in data/raw/*.csv; do
        python -m modules.backtester --strategy "$strategy" --data "$data"
    done
done

# Создать отчеты для всех результатов
for result in output/backtests/*.json; do
    python -m modules.reporter --results "$result"
done
```

## 🚦 Контроль качества

### Проверка работы модулей:
1. **Модуль 1**: Проверить, что файлы с данными создаются в `data/raw/`
2. **Модуль 2**: Проверить, что JSON результаты появляются в `output/backtests/`
3. **Модуль 3**: Проверить, что HTML отчеты открываются в браузере

### Признаки проблем:
- **Нет выходных файлов**: Модуль завершился с ошибкой
- **Пустые файлы**: Проблемы с источником данных или стратегией
- **Ошибки в отчетах**: Некорректные входные данные для модуля

## 🎯 KPI и метрики проекта

### Технические метрики:
- **Время сбора данных**: <10 минут за месяц данных
- **Время бэктестинга**: <5 минут на стратегию
- **Время создания отчета**: <2 минут
- **Размер данных**: ~10-50MB за месяц по одному символу

### Бизнес-метрики:
- **Количество протестированных стратегий**: Цель >10/неделю
- **Покрытие рыночных условий**: Тестирование на разных периодах
- **Качество отчетов**: Все отчеты должны содержать анализ рисков

## 🔧 Решение типичных проблем

### "Модуль не запускается":
```bash
# Проверить наличие зависимостей
pip install -r requirements.txt

# Проверить правильность команды
python -m modules.data_collector --help
```

### "Нет результатов":
- Проверить правильность путей к файлам
- Убедиться, что предыдущий модуль завершился успешно
- Проверить права доступа к папкам

### "Отчет не открывается":
- Убедиться, что HTML файл создался
- Попробовать открыть в другом браузере
- Проверить наличие JavaScript (нужен для графиков)
