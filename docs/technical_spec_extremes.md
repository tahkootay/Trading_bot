# 📑 Техническое задание: модуль статистического анализа экстремумов

## 1. Цель

Разработать модуль для статистического анализа экстремумов цены на
криптовалютных парах (по умолчанию SOL/USDT).\
Основная задача первой версии:\
- Определять локальные экстремумы цены (минимумы/максимумы).\
- Отбирать экстремумы, после которых цена смещалась минимум на **±3
USDT**.\
- Для каждого экстремума фиксировать ключевые технические индикаторы и
рыночный контекст.\
- Сохранять данные в таблицу для последующего анализа (статистика,
графики, ML).

------------------------------------------------------------------------

## 2. Источник данных

-   Использовать существующий модуль сбора данных (исторические свечи
    OHLCV).\
-   Поддержка гибких параметров:
    -   торговая пара (`symbol`)\
    -   таймфрейм (`timeframe`)\
    -   период анализа (`start_date`, `end_date`).

------------------------------------------------------------------------

## 3. Алгоритм работы

### 3.1 Определение экстремумов

-   Поиск локальных минимумов и максимумов (метод скользящего окна /
    алгоритмы детекции пиков).\
-   Экстремум фиксируется только если от него цена сместилась на ≥ 3
    USDT.

### 3.2 Сбор данных по экстремуму

Для каждой точки рассчитываются:\
- **Индикаторы**\
- EMA20, EMA50, EMA100, EMA200\
- RSI (14)\
- Bollinger Bands (верхняя/средняя/нижняя граница)\
- MACD, MACD Signal, MACD Histogram\
- Volume (и средний за N свечей)\
- ATR (волатильность)\
- **Контекстные данные**\
- направление движения после экстремума\
- сила движения (в \$ и %)\
- время достижения 3 USDT (если условие выполнено)\
- положение относительно EMA200 (above/below)\
- уровень волатильности (high/low).

### 3.3 Сохранение

-   Данные сохраняются в таблицу (pandas DataFrame / CSV / БД).\
-   Структура таблицы фиксированная, с возможностью расширения под новые
    индикаторы.

------------------------------------------------------------------------

## 4. Визуализация

-   **Базовый уровень**:
    -   Таблица с экстремумами и метриками.\
    -   График цены с отметками экстремумов.\
-   **Расширенный уровень**:
    -   Heatmap (корреляция индикаторов с направлением движения).\
    -   Boxplot/violin plot (распределение значений индикаторов для
        успешных/неуспешных экстремумов).

------------------------------------------------------------------------

## 5. Масштабируемость

-   Возможность добавления новых индикаторов.\
-   Поддержка любых торговых пар и таймфреймов.\
-   Подготовка базы для дальнейших исследований:
    -   кластеризация экстремумов\
    -   прогноз движения (ML-модели)\
    -   статистическая оценка вероятности движения.

------------------------------------------------------------------------

## 6. Технические детали реализации

-   Язык: Python\
-   Основные библиотеки:
    -   **pandas, numpy** --- обработка данных\
    -   **TA-Lib / pandas-ta** --- индикаторы\
    -   **matplotlib / plotly / seaborn** --- визуализация\
-   Хранение: CSV или SQLite (опционально PostgreSQL при
    масштабировании).

------------------------------------------------------------------------

## 7. Выходные данные

-   Таблица с экстремумами и метриками (DataFrame/CSV/БД).\
-   График с отметками экстремумов.\
-   По необходимости --- отчёт (heatmap, boxplot).
