### 📋 Рекомендации по использованию

#### Для разработки:
1. **Docker**: Используйте Docker вместо venv
2. **Модули**: Разрабатывайте в `modules/` с CLI интерфейсами
3. **Данные**: Сохраняйте в `data/raw/` и `data/test/`
4. **Результаты**: Автоматически в `output/`

#### Для тестирования:
1. Используйте данные из `data/bybit_futures/` или `data/blocks/`
2. Тестируйте каждый модуль независимо
3. Проверяйте работу CLI интерфейсов

#### Для продакшена:
1. Используйте только файлы из корня проекта
2. Игнорируйте `archive/` полностью
3. Настройте CI/CD на основе модульной структуры
