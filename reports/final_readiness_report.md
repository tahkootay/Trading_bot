- MACD семейство: `macd_line`, `macd`, `macd_signal`, `macd_histogram`
- Bollinger Bands: `bb_position`, `bb_width`, `bb_position_lag_1`, `bb_position_lag_3`

## 🚀 Рекомендации для обучения

### Готовые input shapes для LSTM:
- **Window size 20**: (20, 33) → 51,956 train samples
- **Window size 30**: (30, 33) → 51,946 train samples
- **Window size 60**: (60, 33) → 51,916 train samples

### Рекомендуемые параметры:
- **Batch size**: 64
- **Epochs**: 30-50 с early stopping
- **Learning rate**: 0.001 с ReduceLROnPlateau
- **Architecture**: LSTM(64) → LSTM(32) → Dense(16) → Dense(8) → Dense(1)

### Команды для запуска:
```bash
# Keras/TensorFlow версия (требует установки TensorFlow)
python3 main.py train --model lstm --horizon 3 --window 30 --epochs 30

# Или напрямую
python3 src/models/lstm/real_lstm_model.py

# PyTorch версия (автоматически установит PyTorch)
python3 src/models/lstm/torch_lstm_model.py
```
