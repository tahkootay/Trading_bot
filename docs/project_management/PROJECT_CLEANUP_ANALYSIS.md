## 🎯 Рекомендуемые действия

### Фаза 1: Безопасное удаление (можно восстановить)
1. Переместить в `archive/temp_data/`:
   - `models/` → `archive/temp_data/old_models/`
   - `src/` → `archive/temp_data/old_src/`
   - ML скрипты из `scripts/` → `archive/temp_data/old_scripts/`

### Фаза 2: Очистка данных
1. Переместить `data/enhanced/` → `archive/temp_data/old_enhanced_data/`
2. Переместить `data/processed/` → `archive/temp_data/old_processed_data/`

### Фаза 3: Полное удаление
1. Удалить `venv/` (после подтверждения, что не используется)
2. Удалить временные файлы из `archive/temp_data/catboost_info/`

### Фаза 4: Добавить в .gitignore
```
venv/
__pycache__/
*.pyc
*.pyo
.env
.vscode/
.idea/
models/
catboost_info/
```

## 🚀 Преимущества очистки

1. **Производительность**:
   - Быстрая индексация IDE
   - Быстрое клонирование репозитория
   - Меньше места на диске

2. **Ясность архитектуры**:
   - Только актуальные файлы
   - Четкое разделение модулей
   - Простая навигация

3. **Разработка**:
   - Меньше путаницы 
   - Фокус на новой архитектуре
   - Легче тестирование

## ⚠️ Предостережения

- Всегда делать backup перед массовым удалением
- Проверить, что никакие файлы не импортируются в новых модулях
- Сначала перемещать в archive, потом удалять
- Проверить работу всех модулей после очистки
