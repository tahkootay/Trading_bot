# Trading Bot System v2.0 🤖

Модульная система анализа криптовалютной торговли с настраиваемыми параметрами, современной архитектурой и поддержкой LSTM/Random Forest моделей.

## 🎯 Цель проекта

Система предназначена для:
- Автоматического сбора исторических данных с биржи Bybit
- Расчета технических индикаторов (33+ показателя)
- Обучения ML-моделей с настраиваемыми горизонтами предсказания
- Бэктестирования торговых стратегий на исторических данных
- Анализа производительности моделей

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
# Создание виртуального окружения
python -m venv venv
source venv/bin/activate  # Linux/Mac
# или venv\Scripts\activate  # Windows

# Установка зависимостей
pip install -e .
```

### 2. Сбор данных

```bash
# Сбор данных SOLUSDT за последнюю неделю
python main.py collect --symbol SOLUSDT --timeframe 5m --period week

# Или напрямую через модуль
python -m modules.data_collector --symbol SOLUSDT --timeframe 5m --period week
```

### 3. Подготовка данных для ML

```bash
# Добавление технических индикаторов
python -m modules.data_collector.indicators input_data.csv output_with_indicators.csv

# Добавление продвинутых индикаторов (50+ признаков)
python -m modules.data_collector.advanced_indicators input_data.csv output_advanced.csv

# Подготовка данных для ML (таргеты, лаги, разбивка, масштабирование)
python -m modules.data_collector.ml_data_prep input_advanced.csv data/processed --targets 3
```

### 4. Обучение модели

```bash
# Обучение базовой модели
python scripts/train_model.py

# Обучение оптимизированных моделей (топ-25 признаков)
python scripts/training/train_optimized_models.py
```

### 5. Анализ результатов

```bash
# Анализ важности признаков
python scripts/analysis/analyze_feature_importance.py

# Сравнение моделей
python scripts/analysis/compare_all_models.py

# Бэктестирование
python tests/quick_backtest.py
```

## 📊 Описание модулей

### modules/data_collector/
**Назначение:** Сбор и обработка торговых данных

**Возможности:**
- Сбор исторических данных с Bybit API
- Расчет базовых технических индикаторов (MA, RSI, MACD, etc.)
- Расчет продвинутых индикаторов (50+ признаков)
- Подготовка данных для машинного обучения
- Создание таргетов и лаговых признаков

**Входные данные:** Параметры торговой пары, таймфрейм, период
**Выходные данные:** CSV файлы с OHLCV + индикаторы

**Как запустить:**
```bash
python -m modules.data_collector --symbol BTCUSDT --timeframe 1h --period month
```

### modules/ml_training/
**Назначение:** Обучение и управление ML-моделями

**Возможности:**
- Обучение моделей (Random Forest, XGBoost)
- Сохранение/загрузка моделей с версионированием
- Расчет метрик производительности
- ML-бэктестирование торговых стратегий
- Сравнение версий моделей

**Входные данные:** Обработанные CSV файлы из data/processed/
**Выходные данные:** Обученные модели в models/, метрики производительности

**Как запустить:**
```bash
# Список доступных моделей
python -m modules.ml_training list

# Сравнение моделей
python -m modules.ml_training compare v1 v2

# Использование бэктестера
from modules.ml_training import MLBacktester
backtester = MLBacktester("models/rf_v1.pkl", "data/test.csv")
results = backtester.run_backtest()
```

### scripts/analysis/
**Назначение:** Скрипты для анализа данных и моделей

**Включает:**
- `analyze_feature_importance.py` - анализ важности признаков
- `analyze_optimized_performance.py` - сравнение производительности моделей
- `analyze_backtest_trades.py` - детальный анализ торговых сделок
- `show_feature_importance.py` - визуализация важности признаков
- `compare_all_models.py` - сравнение всех доступных моделей

### scripts/data/
**Назначение:** Скрипты обработки данных

**Включает:**
- `create_optimized_dataset.py` - создание оптимизированного датасета
- `create_optimized_indicators.py` - создание оптимизированной версии индикаторов
- `add_lag_features.py` - добавление лаговых признаков
- `prepare_october_data.py` - подготовка тестовых данных

### scripts/training/
**Назначение:** Скрипты обучения моделей

**Включает:**
- `train_optimized_models.py` - обучение моделей на топ-25 признаков

## 🔧 Конфигурация

Система использует YAML файлы конфигурации в директории `config/`:

- `default.yaml` - основные настройки
- `indicators.yaml` - настройки технических индикаторов  
- `indicators_optimized.yaml` - оптимизированные настройки (топ-25)

## 📊 Производительность

### Текущие результаты:
- **Точность моделей:** 55-58% на 3-10 барах вперед
- **Топ-25 признаков:** Снижение шума на 40% при сохранении качества
- **Скорость обучения:** Random Forest ~30 сек, XGBoost ~45 сек
- **Объем данных:** Поддержка до 1M+ записей

### Оптимизация:
- Использование только значимых признаков (топ-25)
- Эффективное масштабирование данных
- Кэширование промежуточных результатов
- Параллельная обработка для индикаторов

## 🚨 Важные замечания

1. **Только для образовательных целей** - система не является финансовым советом
2. **Бэктестирование ≠ будущие результаты** - исторические данные не гарантируют будущую прибыльность
3. **Управление рисками** - всегда используйте стоп-лоссы и контролируйте размер позиций
4. **Тестирование на demo** - обязательно тестируйте на демо-счете перед реальной торговлей
